# Datheon Internship Projects

A collection of frontend development projects built as part of my **Datheon Full Stack Web Development Internship**.

This repository brings together practical projects focused on JavaScript fundamentals, responsive user interfaces, API integration, asynchronous programming, and real-world frontend development practices.

## 📌 Projects

### 1. TaskFlow — To-Do List App

A responsive task management application designed to help users organize tasks, manage deadlines, and track their progress.

**Key Features**
- Create and delete tasks.
- Organize tasks by category.
- Mark tasks as completed or active.
- Search tasks by title.
- Filter tasks by completion status.
- Persist task data using browser local storage.
- Display task statistics.
- Responsive user interface.

**Technologies:** HTML5, CSS3, Vanilla JavaScript, LocalStorage API.

[View Source Code](./todo-app/)

### 2. Weather App

A weather application that retrieves weather information for a searched city and presents current conditions alongside a multi-day forecast.

**Key Features**
- Search for weather by city.
- Retrieve weather data from a third-party API.
- Display current weather conditions and metrics.
- Show a five-day weather forecast.
- Handle asynchronous requests and API errors.
- Present weather information through a responsive interface.

**Technologies:** HTML5, CSS3, Vanilla JavaScript, REST API, Fetch API, Async/Await.

[View Source Code](./weather-app/)

> Note: The Weather App features listed above describe the intended project scope. Refer to the implementation in `weather-app/` for the currently supported functionality.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension (recommended).

### Run a Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the repository directory:

   ```bash
   cd datheon-internship
   ```

3. Open either `todo-app/index.html` or `weather-app/index.html` using Live Server.

4. Follow any project-specific instructions in its directory.

Some features, particularly those using external APIs, may require an API key and an active internet connection.

## 🔐 Security & Configuration

- Do not commit API keys, passwords, tokens, or other secrets.
- Keep private configuration out of version control.
- Follow each API provider's terms and usage limits.
- Review project-specific documentation for configuration requirements.
